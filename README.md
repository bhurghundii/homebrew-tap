# bhurghundii/homebrew-tap

Homebrew formulae for [vibecheck](https://github.com/bhurghundii/vibecheck.dev).

```sh
brew install bhurghundii/tap/vibecheck
```

`vibecheck` quizzes you on your own code change in the terminal, using the same questions and grading as the vibecheck server, with your own `ANTHROPIC_API_KEY`. See [Quiz yourself locally](https://bhurghundii.com/vibecheck.dev/local-cli/).

## How this repo is updated

Don't edit `Formula/vibecheck.rb` by hand. It is generated by [`scripts/brew_formula.py`](https://github.com/bhurghundii/vibecheck.dev/blob/main/scripts/brew_formula.py) and pushed here by the vibecheck.dev release workflow on every `v*` tag. Every push and PR here runs a real `brew install --build-from-source` and `brew test` on macOS (`.github/workflows/test.yml`).
